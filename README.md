# Portfolio

This repository contains a selection of my projects in data analysis, business intelligence, financial modeling, and process automation, using Python, SQL, Power BI, and Excel.

## Projects

### HR Data Analysis - Sailfort Motors

A Python-based HR analytics project investigating the factors associated with employee attrition at Sailfort Motors. The analysis includes data cleaning, exploratory data analysis, data visualization, statistical analysis, machine learning models, and predictive modeling, with key findings presented in an executive summary for stakeholders.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

**Key topics:** Data cleaning · EDA · Classification · Machine Learning · Model Evaluation

### Financial Modeling & Valuation - VIVARA Benchmark

A financial feasibility study evaluating a Public-Private Partnership (PPP) for a high-end jewelry store in Salvador, benchmarked against Vivara (VIVA3).

The project includes revenue and expense projections, income statement modeling, CAPEX and working capital analysis, discounted cash flow (DCF) valuation, NPV, IRR, payback period, sensitivity analysis, and risk assessment.

**Tools:** Excel, Word

---

### Financial Analysis - Gym Operations

A yearly financial analysis of a gym's operations across multiple activity lines, including Pilates, hydrogymnastics, hydrotherapy, and children's and adult swimming

The analysis examines **client volume, seasonal trends, revenue, expenses, profitability, churn, and average monthly revenue**, providing an overview of the financial performance of each activity.

**Tools:** Google Sheets
